# 経営計画 探索スクリプト

Excelの `経営指標`、`栽培スケジュール`、`固定資産` を読み込み、OR-Toolsで輪作計画を探索します。結果はCSVとExcelに出力します。

## 前提

- Pythonは `venv` を使います。
- 必要な主なパッケージは `openpyxl` と `ortools` です。
- 入力Excelには以下のシート名が必要です。
  - `経営指標`
  - `栽培スケジュール`
  - `固定資産`
  - `経営計画`

## ファイル構成

- `keiei_plan.py`  
  Excel読取、PL/CF計算、制約チェックの共通処理です。通常は直接実行しません。

- `validate_current_plan.py`  
  現在のExcelシートをPythonで再計算し、Excelの計算結果と突き合わせます。

- `optimize_rotation.py`  
  輪作計画を探索し、結果を `out` フォルダーへ出力します。

## データチェック

入力Excelの現行計画を検算します。

```powershell
.\venv\Scripts\python.exe validate_current_plan.py --workbook 経営計画_20260521.xlsx
```

注意: `validate_current_plan.py` は主に既存シートとの検算用です。4区画フォーマットや手入力済み計画の状態によっては、現行計画との差分が出ることがあります。探索用データとして重要なのは、`栽培スケジュール` のID重複や収益・費用の欠損がないことです。

## 探索の実行

4区画で標準条件の探索をします。

```powershell
.\venv\Scripts\python.exe optimize_rotation.py --workbook 経営計画_20260521.xlsx --fields 4
```

8区画で探索します。

```powershell
.\venv\Scripts\python.exe optimize_rotation.py --workbook 経営計画_20260521.xlsx --fields 8
```

200時間を月労働時間のハード上限、150時間を努力目標として探索します。

```powershell
.\venv\Scripts\python.exe optimize_rotation.py --workbook 経営計画_20260521.xlsx --fields 8 --labor-cap 200 --soft-labor 150
```

## オプション

- `--workbook`  
  読み込むExcelファイルを指定します。

- `--fields`  
  探索する区画数を指定します。3区画または4区画では、既存の `経営計画` シート形式に近いExcelを出力します。5区画以上では、`経営計画` シートに `＜輪作計画表＞` と `＜労働時間算定表＞` をまとめた確認用Excelを出力します。

- `--labor-cap`  
  月別労働時間の絶対上限です。既定値は `240` です。

- `--soft-labor`  
  努力目標の労働時間です。超過すると目的関数で減点されます。既定値は `200` です。

## 出力

探索ごとに `out` 配下へサブフォルダーを作成します。

例:

```text
out/経営計画_20260521_8fields_cap200_soft150_20260521_190446/
```

出力される主なファイル:

- `*_plan.csv`  
  採用された作付候補の一覧です。

- `*_monthly.csv`  
  月別の労働時間、収益、費用、所得です。

- `*_grid.csv`  
  経営計画シートに近い作物ID・工程グリッドです。

- `*.xlsx`  
  Excelブックです。3区画または4区画の場合は、既存の `経営計画` シートへ探索結果を書き戻します。5区画以上の場合は、`経営計画` シートを作り直し、輪作計画表と労働時間算定表を確認できる簡易レポートとして出力します。

## 制約と目的関数

現在の探索では、主に以下を扱います。

- 同一区画で作付期間が重ならない
- 収穫後2か月を空ける
- 同じ作物は休栽年数を満たすまで同一区画で再作付しない
- 月別労働時間を `--labor-cap` 以下にする
- `--soft-labor` 超過を目的関数で減点する
- 作付由来の利益を最大化する

## 注意点

- Excel数式は `openpyxl` では計算されません。出力されたExcelは、Excelで開いた時に再計算されるように設定しています。
- 5区画以上のExcel出力は、PL/CFまで含む完全な経営計画表ではありません。輪作計画表と労働時間算定表を確認するための簡易レポートです。PL/CFはCSVや標準出力の指標で確認してください。
- `栽培スケジュール` のA列IDは一意にしてください。
- 収穫月がある作型は、粗収益/月が空または0にならないようにしてください。
- 播種月がある作型は、経営費が空にならないようにしてください。
